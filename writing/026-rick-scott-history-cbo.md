# Issue #26 — Add history and CBO analysis to the Rick Scott plan proposal

**Issue:** https://github.com/Visualize-Policy/research-writing-admin/issues/26

Write two short, sourced pieces about Sen. Rick Scott's 2022 "11 Point Plan to Rescue America": a
**history** (where the plan came from, what it said about health care, how it was revised or walked
back) and a **CBO analysis** (did the Congressional Budget Office or another neutral group ever
estimate its effects? If not, say so plainly and note where you looked). If you can, also suggest
text for the summary and the list of changes, which are still placeholders.

**Where this ends up:** the proposal page's data file,
[`rick-scott.json`](https://github.com/Visualize-Policy/health-dashboard/blob/main/site_code/src/data/proposals/rick-scott.json)
in the health-dashboard repo. You don't edit that file; write here, and a maintainer copies the
finished text in. For a finished example of both pieces, see
[`chip-repeal.json`](https://github.com/Visualize-Policy/health-dashboard/blob/main/site_code/src/data/proposals/chip-repeal.json).

**History** is a list of dated events, oldest first. For each: a date (a year like `2022`, a month
like `2022-02`, or a full date like `2022-02-22`), a short headline, and a sentence or two of detail
with a source link.

**CBO analysis** is one short block: was there an estimate (yes or no); if yes, a summary and the
link; and a note putting it in context. If no estimate exists, the note says what you searched
(for example cbo.gov) and when.

# Issue #1 — Hook module 1: county premium/coverage lookup

**Issue:** https://github.com/Visualize-Policy/research-writing-admin/issues/1

Design the content and UX for a landing "hook": ask a visitor if they'd like to know how much
people in their county pay for health insurance and where they get it, using their own county as
the entry point. Real coverage-type and uninsured-rate data already exists at the county level;
premium data only exists at the state level, which the design needs to handle honestly.
